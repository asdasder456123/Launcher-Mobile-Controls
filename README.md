# Launcher Mobile Controls

> إعدادات أزرار وتحكم Minecraft Launcher على الهاتف  
> Mobile control layouts for Minecraft launchers.

---

## 🇪🇬 العربية

### 📱 ما هو هذا المشروع؟

هذا المستودع عبارة عن مكتبة لملفات **JSON** الخاصة بإعدادات أزرار وتحكم Minecraft على الهاتف.

الهدف هو توفير تخطيطات تحكم جاهزة يمكن للاعبين تحميلها واستخدامها مع اللانشرات التي تدعم ملفات التحكم المخصصة.

المشروع **ليس برنامجًا أو لانشرًا بحد ذاته**، ولا يحتوي على كود مصدر للانشر.

### 📂 ماذا ستجد هنا؟

سيتم إضافة ملفات التحكم بصيغة:

```text
.json

وكل ملف يمثل تخطيطًا معينًا لأزرار التحكم على شاشة الهاتف.

قد تختلف التخطيطات حسب طريقة اللعب، مثل:

🎮 PvP

⛏️ Survival

🏗️ Building

🕹️ General / Default

📱 تخطيطات مخصصة للهاتف


⬇️ طريقة استخدام ملفات التحكم

1. اختر ملف الـ JSON الذي تريد استخدامه.


2. حمّل الملف من GitHub.


3. انقل الملف إلى مجلد ملفات التحكم الخاص باللانشر الذي تستخدمه.


4. افتح اللانشر.


5. حمّل أو اختر تخطيط التحكم من إعدادات التحكم المخصصة.


6. إذا كان اللانشر يتطلب اسمًا محددًا للملف، استخدم الاسم المطلوب منه.



> ⚠️ مسار الملفات واسم الملف المطلوب قد يختلفان حسب اللانشر والإصدار المستخدم.



📁 مثال

بعض إصدارات اللانشرات قد تستخدم مجلدًا مشابهًا لـ:

Android/data/<launcher-package>/files/controlmap/

وقد يكون اسم الملف المطلوب مثل:

default.json

لا تستخدم هذا المسار أو الاسم بشكل أعمى؛ اتبع طريقة اللانشر والإصدار الذي تستخدمه.

🇬🇧 English

📱 What is this project?

This repository is a library of JSON files containing custom Minecraft mobile control layouts.

The goal is to provide ready-to-use control layouts that players can download and use with launchers that support custom control-layout files.

This project is not a launcher and does not contain launcher source code.

📂 What will you find here?

The repository will contain control-layout files using the:

.json

format.

Each JSON file represents a different touchscreen control layout.

Layouts may be designed for different play styles, including:

🎮 PvP

⛏️ Survival

🏗️ Building

🕹️ General / Default

📱 Custom mobile layouts


⬇️ How to use a layout

1. Choose the JSON layout you want.


2. Download the file from GitHub.


3. Move the file into the control-layout directory used by your launcher.


4. Open your launcher.


5. Load or select the layout from the custom controls settings.


6. If your launcher requires a specific filename, use the filename required by that launcher.



> ⚠️ The file location and required filename may vary depending on the launcher and version.



📁 Example

Some launcher versions may use a directory similar to:

Android/data/<launcher-package>/files/controlmap/

The required filename may also be something like:

default.json

Do not assume this path or filename applies to every launcher. Follow the instructions for your specific launcher and version.
